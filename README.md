## Publish on GitHub Pages
1. Create a public repository on your GitHub account (for example `17eare401-notes`).
2. Upload the *contents* of this folder so that `index.html` is at the top level, together with `assets/`, `fig/` and `.nojekyll`.
3. Settings > Pages > Build and deployment: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. The site appears at `https://<username>.github.io/<repository>/` within a minute or two.

## Presenting in class
Open a chapter and press **P**. Arrow keys, Space, Page Up/Down or a clicker change slides; **O** overview; **F** full screen; **Esc** exits.

## Protecting authorship
Push to GitHub before sharing the link (the dated history is your record), archive the URL at web.archive.org, optionally deposit the zip on Zenodo for a DOI, and use GitHub's DMCA process (github.com/contact/dmca) against unauthorised copies. Search the provenance identifier to find copies.
